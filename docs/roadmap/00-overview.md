# Scoresheets App Branch Plan

This project is split into branch-focused steps so each pull request has one clear objective.

## Branch order

1. feat/android-expo-setup
2. feat/core-data-model
3. feat/take5-round-scoring
4. feat/pickomino-total-scoring
5. feat/session-history-export
6. feat/test-build-apk

## Scope lock for MVP

- Supported games: Take 5! and Pick-omino only.
- Input mode: typed numbers.
- Traffic expectation: low (about 5 to 50 sessions per game).
- Offline only: no cloud sync in v1.
- Deployment: personal Android APK sideload.
