# Branch: feat/web-pwa-setup

## Goal
Create a stable web-first app shell that is installable and works offline.

## Tasks

1. Set up web app shell with Home, New Session, and Session History views.
2. Add app manifest with name, icons, display mode, and start URL.
3. Add service worker registration and basic caching strategy for app shell assets.
4. Add offline fallback behavior for first-party routes.
5. Add development scripts and baseline README instructions for local run and PWA checks.

## Done when

1. App loads in browser via local dev server.
2. Browser install prompt is available on supported devices.
3. App launches from home screen/desktop icon.
4. App continues to open and navigate in airplane mode after first load.
