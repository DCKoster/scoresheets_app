# scoresheets_app

Offline Android-first scoresheets app for board/card/dice games.

Current MVP scope:

- Take 5! with per-round point entry and automatic totals.
- Pick-omino with single total score entry per player.
- Typed numeric input.
- Personal local use (offline), no cloud sync.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start Expo and open on Android:

```bash
npm run android
```

If you do not have an emulator, install Expo Go on your Android phone and run:

```bash
npm start
```

Then scan the QR code.
