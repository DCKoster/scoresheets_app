# scoresheets_app

Web-first scoresheets project.

## Start here

Use the small browser app in [web_app](web_app).

### Web app quick run

1. Open [web_app/index.html](web_app/index.html) in your browser.
2. Create a session for Take 5! or Pick-omino.
3. Saved sessions are stored in browser local storage.
